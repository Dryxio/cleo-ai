# CardDecks Opcodes

> 2 opcodes in this class

## Quick Reference

| Opcode | Name | Description |
|--------|------|-------------|
| `059D` | SHUFFLE_CARD_DECKS |  |
| `059E` | FETCH_NEXT_CARD | Returns a random number between 1 and 52, inclusive |

## Detailed Reference

### `059D` SHUFFLE_CARD_DECKS

**Class:** `CardDecks.Shuffle`
**Flags:** static

**Input:**
- `type: int`

**Details:**

This command generates arrays of randomly ordered numbers between 1 and 52, the number of arrays determined by the value of this command. The arrays simulate the random order when shuffling a standard 52-card deck. FETCH_NEXT_CARD is used to read the elements of the arrays. A value of `0` clears the deck by filling the arrays with the number 0. The arrays do not reset when loading different game sessions so they carry over.

---

### `059E` FETCH_NEXT_CARD
Returns a random number between 1 and 52, inclusive

**Class:** `CardDecks.FetchNextCard`
**Flags:** static

**Output:**
- `number: int (variable)`

**Details:**

This command gets the value of the element in an array generated by SHUFFLE_CARD_DECKS, which means a value between `1` and `52` is possible to get. This simulates the fetching of a card from a randomly shuffled deck of 52 cards. Each time the command is called, it iterates through the array. When it reaches the end of the array, it moves onto the next array if it exists. When it finishes all available arrays, it returns back to the first array and repeats the process. If the deck is cleared, it gets the value `0`.
