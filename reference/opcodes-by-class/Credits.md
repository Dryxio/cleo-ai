# Credits Opcodes

> 3 opcodes in this class

## Quick Reference

| Opcode | Name | Description |
|--------|------|-------------|
| `0434` | START_CREDITS | Makes the credits scroll up the screen |
| `0435` | STOP_CREDITS | Stops the credits text from showing |
| `0436` | ARE_CREDITS_FINISHED | Returns true if the credits have finished |

## Detailed Reference

### `0434` START_CREDITS
Makes the credits scroll up the screen

**Class:** `Credits.Start`
**Flags:** static

---

### `0435` STOP_CREDITS
Stops the credits text from showing

**Class:** `Credits.Stop`
**Flags:** static

---

### `0436` ARE_CREDITS_FINISHED
Returns true if the credits have finished

**Class:** `Credits.AreFinished`
**Flags:** static, condition
